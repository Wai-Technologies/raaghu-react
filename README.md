Raaghu React is a design system and a set of reusable React components for building web applications faster and with consistent UI/UX.

## Installation

```bash
npm install raaghu-react
```

## Usage

Import the required components in your React application:

```javascript
import { RaaghuButton } from "raaghu-react";
```
